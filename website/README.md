# Nova — Modern Static Website

A beautiful, responsive, accessible website template with dark mode, built with plain HTML/CSS/JS. No build tools required.

## Quick start

Open `index.html` directly in your browser, or serve the folder locally:

```bash
cd /workspace/website
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Edit `assets/styles.css` for colors, spacing, and components.
- Edit `index.html` sections: Hero, Features, Showcase, Pricing, FAQ, Contact.
- Edit `assets/script.js` for theme toggle, mobile nav, and reveal animations.

## Deploy

- Any static hosting works: GitHub Pages, Netlify, Vercel, S3, your own server.
- Upload the contents of this folder as-is.
